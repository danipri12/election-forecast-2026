# election-forecast-2026
AI-assisted forecasting of the 2026 U.S. Senate elections using historical data, statistical modeling, polling, and predictions from Kalshi.

## Project Files

| File | Description |
|---|---|
| `presidential_baseline.py` | Establishes a historical baseline for predicting Senate election outcomes using presidential voting patterns. |
| `final_forecast.py` | Generates the final 2026 Senate election forecasts using historical data and prediction-market probabilities. |
| `audit_forecast.py` | Audits and evaluates forecast predictions against election results. |
| `compare_external.py` | Compares project predictions with external forecasts from sources such as Decision Desk HQ. |
| `README.md` | Documents the project, methodology, results, and data sources. |
